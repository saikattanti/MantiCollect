# Getting Support for MantiCollect

Thank you for using MantiCollect (A Mantitup Product)! This guide explains how to get help and report issues.

---

## 1. Where to Ask Questions

* **General Questions & Community Help**: Use [GitHub Discussions](https://github.com/saikattanti/MantiCollect/discussions) (or the Discussions tab) for:
  - Setup assistance and configuration advice.
  - Discussion of download providers and format selection.
  - Ideas and feature discussions.
* **Bug Reports**: If you have identified a specific bug, broken download provider, or error message, open a [Bug Report](https://github.com/saikattanti/MantiCollect/issues/new/choose).
* **Feature Requests**: To propose a new capability or architectural improvement, submit a [Feature Request](https://github.com/saikattanti/MantiCollect/issues/new/choose).
* **Security Issues**: For security vulnerabilities, do not use public channels. Follow the instructions in [SECURITY.md](SECURITY.md).

---

## 2. Before Opening an Issue

To help us resolve issues quickly, please:

1. **Check Existing Issues**: Search the [Issue Tracker](https://github.com/saikattanti/MantiCollect/issues) to verify if the issue has already been reported.
2. **Review Documentation**:
   - [README.md](README.md): Project overview and quick start.
   - [Distribution & Installation Guide](docs/DISTRIBUTION_AND_INSTALLATION.md): Setup and troubleshooting.
   - [Architecture Guide](docs/ARCHITECTURE.md): Technical deep-dive.
3. **Verify App Version**: Check your MantiCollect version under **About** in the sidebar.
4. **Reproduce with Minimal Steps**: Verify whether the problem occurs consistently.

---

## 3. Privacy & Sensitive Data Warning

When posting issues, logs, or error traces:

* :warning: **Never post passwords, API tokens, S3 secret access keys, or SFTP credentials.**
* :warning: **Never post private download URLs or URLs containing signed authentication parameters** (e.g. `?token=...`, `?sig=...`).
* Sanitize all logs before submitting.
