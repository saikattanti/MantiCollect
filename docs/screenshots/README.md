## Capture Guidelines
* **Display Scaling**: 100% or 125% DPI scaling on Windows.
* **Theme**: Dark mode preferred (matches default `--mv-bg: #0b0d12`).
* **Format**: PNG, optimized without lossy compression.
* **Resolution**: 1920x1080 window frame or clean 1280x800 cropped application window.
* **Privacy**: Ensure test URLs and filenames do not contain personal data or copyrighted content.
